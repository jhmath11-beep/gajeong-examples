코딩을 몰라도 됩니다. 프롬프트를 복사해 ChatGPT·Claude·Gemini 같은 AI 대화창에 붙여넣기만 하면 됩니다.

먼저 고르기 — HTML 하나로? 구글 시트로?

📄 HTML 하나로 · GitHub Pages(무료)

계산 · 연습 · 타이머 · 인쇄 · 내 기록 저장(브라우저에). 서버·로그인 없음. 파일 1개.
📊 Apps Script로 · 구글 시트에 모으기

제출 · 집계 · 교사 대시보드. 파일 2개(Code.gs + index.html). 개인 gmail 권장.
🔥 Firebase로 · 고급
실시간으로 쌓이고, 사진을 받고, 전시회처럼 보여 준다.
제출 즉시 TV에 반영 · 작품 사진 · 교사 승인 후 공개. Apps Script로 충분하면 그쪽이 더 쉽습니다.

❓ 헷갈리면 이 질문 하나: “학생 30명이 낸 걸 내가 한 화면에서 봐야 하나?” → 예 = Apps Script, 아니오 = HTML.
HTML로 시작해도 됩니다. 화면을 HTML로 먼저 완성·배포한 뒤, 필요할 때 “구글 시트에 모으기”만 Apps Script로 옮기는 게 가장 안전한 순서입니다.

샘플을 쓰는 세 가지 방법

  1. 그대로 쓰기 — [샘플 열기]로 확인 → 마음에 들면 HTML 샘플은 index.html을 내 GitHub 저장소에 올려 내 주소로. Apps Script·Firebase 샘플은 설치방법을 따라 내 계정에.
  2. 내 버전 만들기 — 각 샘플의 첫 화면 → 키우기 단계 프롬프트를 순서대로 AI에 보내면 비슷한 앱이 처음부터 만들어집니다.
  3. 바꿔 쓰기(도전과제) — 샘플 파일 전체를 AI에 붙여넣고 “샘플 이어 고치기” 프롬프트 + 도전과제 하나. 쉬움 → 보통 → 어려움 순으로.
