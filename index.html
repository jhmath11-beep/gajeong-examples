모두 실제로 동작하는 완성 샘플입니다. 그대로 수업에 쓰셔도 되고, 아래 프롬프트로 내 버전을 처음부터 만들어 보거나, 도전과제로 하나씩 바꿔 보세요.

연수에서 만든 샘플을 그대로 수업에 써 보신 선생님들의 만족도가 높았습니다. 오늘도 같은 방식입니다.

먼저 가르기 — HTML 하나로? Apps Script로?

📄 HTML 하나로 · 경로 B (GitHub Pages)
데이터가 그 기기 안에서 끝난다.
계산 · 연습 · 타이머 · 인쇄 · 내 기록 저장(브라우저에). 서버·로그인 없음. 파일 1개.
📊 Apps Script로 · 경로 E (구글 시트)
여러 사람의 입력을 한 곳에 모은다.
제출 · 집계 · 교사 대시보드. 파일 2개(Code.gs + index.html). 개인 gmail 권장.

❓ 헷갈리면 이 질문 하나: “학생 30명이 낸 걸 내가 한 화면에서 봐야 하나?” → 예 = Apps Script, 아니오 = HTML.
HTML로 시작해도 됩니다. 화면을 HTML로 먼저 완성·배포한 뒤, 필요할 때 “구글 시트에 모으기”만 Apps Script로 옮기는 게 가장 안전한 순서입니다.

샘플을 쓰는 세 가지 방법

  1. 그대로 쓰기 — [샘플 열기]로 확인 → 마음에 들면 HTML 샘플은 index.html을 내 GitHub 저장소에 올려 내 주소로(경로 B). Apps Script 샘플은 설치방법을 따라 내 구글 시트에(경로 E).
  2. 내 버전 만들기 — 각 샘플의 P0 → 키우기 단계 프롬프트를 순서대로 AI에 보내면 비슷한 앱이 처음부터 만들어집니다. 연수 실습용.
  3. 바꿔 쓰기(도전과제) — 샘플 파일 전체를 AI에 붙여넣고 “샘플 이어 고치기” 프롬프트 + 도전과제 하나. 쉬움 → 보통 → 어려움 순으로.
샘플 이어 고치기 — 샘플 파일 전체를 붙여넣고 맨 아래에 도전과제를 적어 보내기
