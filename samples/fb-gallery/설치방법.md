# 작품 제출함 & 온라인 전시회 — 설치 방법 (Firebase 고급)

학생이 휴대폰으로 **작품 사진 1~3장 + 제목·설명**을 내면, 교사는 **자료실**에서 반·단원별로 받아 보고(미제출 번호, 사진 내려받기, 목록 CSV, 코멘트), 승인한 작품만 **전시실**에 걸립니다. 전시실은 TV 슬라이드쇼, 감상평(교사 승인 후 공개), ‘마음에 들어요’(1인 1회)를 지원합니다.

- 필요한 것: Google 계정(**개인 gmail 권장**), PC 크롬, 이 폴더의 `index.html`, `firestore.rules`
- 걸리는 시간: 20~30분
- **먼저 구경만 하려면** `index.html`을 더블클릭하세요. **체험 모드**로 열립니다(이 브라우저에만 저장). 탭을 두 개 열면 한쪽에서 낸 작품이 다른 쪽에 바로 보여요. 자료실은 ‘체험 교사로 보기’, 위쪽 **샘플 넣기**로 예시 작품 8점.

> Apps Script 샘플(gas-*)과 다른 점: 구글 시트 대신 **Firebase**(구글의 앱용 데이터베이스)에 모읍니다. 사진을 다룰 수 있고, 화면이 **실시간**으로 바뀌며, 누가 무엇을 읽고 쓸지는 **보안 규칙**이 서버에서 막습니다.

---

## 0. 꼭 지킬 것 — "새 프로젝트"에만
`firestore.rules`를 붙여넣으면 그 프로젝트의 규칙이 **통째로 바뀝니다.** 이미 다른 사이트·앱이 쓰는 Firebase 프로젝트에 붙이면 그쪽이 조용히 망가집니다. **반드시 이 앱만을 위해 새 프로젝트를 만드세요.**

## 1. 새 Firebase 프로젝트 만들기
1. https://console.firebase.google.com 접속 → **프로젝트 추가(만들기)**.
2. 이름 예: `ga-jeongsi-2026` → Google 애널리틱스는 **꺼도 됩니다** → 만들기.
3. 요금제는 기본 **Spark(무료)** 그대로 둡니다. 결제 계정을 연결하라는 화면이 나와도 이 앱에는 필요 없습니다.

## 2. 웹 앱 등록 → 설정값 붙여넣기
1. 프로젝트 첫 화면에서 **웹(`</>`) 아이콘** → 앱 닉네임 `gallery` → 등록. (Firebase Hosting 체크는 하지 않음)
2. 화면에 나오는 `const firebaseConfig = { apiKey: "...", authDomain: "...", ... };` 에서 **중괄호 `{ }` 안쪽**을 복사합니다.
3. `index.html`을 메모장/VS Code로 열어 맨 위 스크립트의
   ```js
   const FIREBASE_CONFIG = { /* 여기에 붙여넣기 */ };
   ```
   중괄호 안에 붙여넣습니다. 결과 예:
   ```js
   const FIREBASE_CONFIG = { apiKey: "AIza...", authDomain: "ga-jeongsi-2026.firebaseapp.com", projectId: "ga-jeongsi-2026", storageBucket: "...", messagingSenderId: "...", appId: "..." };
   ```
4. 바로 아래 `TEACHER_EMAILS`에 **내 Google 계정**을 적습니다: `const TEACHER_EMAILS = ['내아이디@gmail.com'];`
5. `SETTINGS`에서 전시 이름, 반 이름과 **반별 인원**(미제출 번호 계산), 단원 목록을 수업에 맞게 고칩니다.

> **firebaseConfig는 비밀번호가 아닙니다.** Firebase 공식 문서: API 키는 프로젝트를 "식별"할 뿐이고, 데이터 보호는 **보안 규칙**이 맡습니다("Public by design … not by keeping your Firebase API key secret"). → https://firebase.google.com/docs/projects/api-keys
> 그래서 HTML에 넣어 공개해도 되지만, **3·5단계(로그인 설정·보안 규칙)를 빠뜨리면 안 됩니다.**

## 3. 로그인 켜기 (Authentication)
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **Sign-in method(로그인 방법)** 탭 → **익명** 사용 설정 → 저장. (학생용: 계정 없이 들어오되 기기마다 구분됨)
3. 같은 곳에서 **Google** 사용 설정 → 프로젝트 지원 이메일 고르기 → 저장. (교사용)
   - 공식 문서: 익명 https://firebase.google.com/docs/auth/web/anonymous-auth · Google https://firebase.google.com/docs/auth/web/google-signin

## 4. 데이터베이스 만들기 (Cloud Firestore)
1. **빌드 → Firestore Database → 데이터베이스 만들기**.
2. 위치: **asia-northeast3 (서울)** — 한 번 정하면 못 바꿉니다. (https://firebase.google.com/docs/firestore/locations)
3. 시작 모드는 아무거나 골라도 됩니다(다음 단계에서 규칙을 바꿈).

## 5. 보안 규칙 붙여넣기
1. Firestore Database → **규칙** 탭.
2. **새 프로젝트라 기존 규칙이 기본 내용뿐인지 확인**합니다. 다른 내용이 많이 있으면 멈추세요 — 다른 프로젝트일 수 있습니다.
3. 내용을 모두 지우고 `firestore.rules`를 통째로 붙여넣습니다.
4. 맨 위 `isTeacher()` 안의 `['선생님@gmail.com']`을 **2-4에서 적은 이메일과 똑같이** 바꿉니다. (여러 명이면 `['a@gmail.com', 'b@gmail.com']`)
5. **게시**.

> 화면에서 자료실을 숨기는 것만으로는 안전하지 않습니다. 이 규칙이 서버에서 "교사 이메일이 아니면 남의 작품을 읽지 못함", "학생은 전시 승인 칸을 못 바꿈" 등을 막습니다.

## 6. GitHub Pages로 배포 (경로 B) + 승인된 도메인
1. 연수 때 만든 GitHub 저장소에 `index.html`을 올립니다(폴더째 올려도 됨) → Pages 주소 확인. 예: `https://내아이디.github.io/gallery/`
2. Firebase **Authentication → 설정 → 승인된 도메인 → 도메인 추가** → `내아이디.github.io` 입력. (이걸 안 하면 교사 Google 로그인 창이 "unauthorized-domain"으로 막힙니다)
3. 학생에게 주소(QR)를 줍니다. 교사는 같은 주소에서 **자료실 → Google로 로그인**.

> 내 PC에서 파일을 더블클릭해 연 상태(file://)에서는 Google 로그인이 되지 않습니다. 실제 모드 시험은 Pages 주소에서 하세요.

## 7. 수업에서 쓰기
- **학생**: 제출함 → 반·번호·단원·제목·설명 → **카메라로 찍기**(휴대폰 카메라가 바로 열림) 또는 **사진 고르기** → 제출. 오른쪽 "내가 낸 작품"에서 상태(검토 대기/전시 중/숨김)와 선생님 코멘트를 봅니다. **고치기**로 다시 내면 상태가 ‘검토 대기’로 돌아갑니다.
- **교사 자료실**: 반·단원·상태 고르기 → **제출 현황**(번호 칸: 검은 칸=냄, 빨간 칸=안 냄) → 작품마다 **전시/숨김/사진 1·2·3 내려받기/삭제**, 학생에게만 보이는 **코멘트** → **목록 CSV**(미제출 번호까지 한 줄씩) → **감상평 확인**에서 공개/지우기.
- **전시실**: 승인된 작품이 액자와 작품 라벨(제목·반·한 줄 소개)로 걸립니다. 작품을 누르면 크게 보기·마음에 들어요·감상평. **슬라이드쇼**는 TV용(←/→ 키, ‘자동 넘김’은 눌러야 켜짐).
- 전시실에는 **번호가 보이지 않습니다**(반만). 실명·연락처는 받지 않습니다.

## 8. 비용 0원 유지
- 2026-11-09 공식 문서 기준 **Cloud Storage(사진 파일 저장소)는 무료 요금제에서 쓸 수 없습니다**(2026-02-03부터 Blaze 필요). 그래서 이 앱은 사진을 브라우저에서 **긴 변 1280px 이하 JPEG**로 줄여 Firestore 문서에 함께 저장합니다(작품 한 점의 사진 합계 약 700KB 이하, Firestore 문서 한도 1MiB). → https://firebase.google.com/docs/storage/faqs-storage-changes-announced-sept-2024
- Firestore 무료 한도(하루마다 초기화): **저장 1GiB, 읽기 50,000/일, 쓰기 20,000/일, 삭제 20,000/일, 내보내기 10GiB/월**. → https://firebase.google.com/docs/firestore/quotas
  - 작품 한 점 ≈ 0.1~0.7MB → 1GiB에 대략 1,500점 이상. 학기마다 지난 작품을 CSV·사진으로 받아 두고 **삭제**하면 넉넉합니다.
  - 읽기: 화면을 열 때 보이는 작품 수만큼 읽습니다. 4개 반 × 30명이 하루 몇 번씩 열어도 보통 한도 안입니다. 수십 개 반이 동시에 쓰면 콘솔 **사용량** 탭을 확인하세요.
- 무료 한도를 넘으면 그날은 멈출 뿐 청구되지 않습니다(Spark 요금제 유지 시).

## 9. 학교 계정 vs 개인 gmail
- **교사 로그인**은 개인 gmail이 가장 무난합니다. 학교 Google Workspace 계정은 관리자 설정에 따라 외부 앱 로그인이 막힐 수 있습니다(공식 근거는 확인하지 못한 경험칙).
- **학생**은 계정이 필요 없습니다(익명 로그인). 단, 같은 기기·같은 브라우저에서만 "내가 낸 작품"이 보입니다. 브라우저 기록을 지우면 새 학생으로 취급돼 이전 작품을 고칠 수 없습니다(교사는 그대로 봄).

## 막힐 때
| 증상 | 해결 |
|---|---|
| 위에 "체험 모드"가 계속 보임 | `FIREBASE_CONFIG` 붙여넣기가 안 됨 → 2단계, 저장 후 새로고침 |
| "권한이 없어요. 보안 규칙…" | 5단계 규칙 게시 확인, 규칙의 교사 이메일과 `TEACHER_EMAILS`가 같은지 |
| "익명·Google 로그인을 켜 주세요" | 3단계 |
| "승인된 도메인에 없어요" | 6-2단계 |
| "교사 명단에 없어요" | 로그인한 계정이 `TEACHER_EMAILS`에 없음 |
| 사진이 안 열림 | 아이폰 HEIC 등 일부 형식 → 카메라 앱 설정에서 ‘호환성 우선’ 또는 스크린숏으로 |
