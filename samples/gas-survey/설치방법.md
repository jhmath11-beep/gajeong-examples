# 우리 반 식습관 실태 조사 — 설치 방법

학생이 휴대폰으로 식습관 문항에 답하면 내 구글 시트에 모이고, 교사 화면에서 **문항별 막대그래프 · 반별 비교 · 10초 자동 새로고침 · 서술형 모아보기 · CSV**를 봅니다.

- 필요한 것: 구글 계정(**개인 gmail 권장**), PC 크롬 브라우저, 이 폴더의 `Code.gs`, `index.html`
- 걸리는 시간: 10분 정도
- 먼저 구경만 하려면: `index.html`을 더블클릭하세요. **체험 모드**로 열려서 그 브라우저 안에서만 똑같이 동작합니다(교사 PIN `1234`).

> 학교 Google Workspace 계정은 관리자 설정 때문에 "모든 사용자" 공개가 막히는 경우가 있습니다(공식 문서 근거는 확인하지 못한 경험칙). 막히면 개인 gmail로 다시 만드세요.

---

## 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 엽니다.
2. 왼쪽 위 제목을 `식습관 조사`처럼 바꿉니다.

## 2. Apps Script 열고 코드 붙여넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**.
2. 왼쪽 `Code.gs`의 내용을 **모두 지우고** 이 폴더의 `Code.gs`를 통째로 붙여넣습니다.
3. 왼쪽 **파일** 옆 **+** → **HTML** → 이름 `index` (정확히 `index`).
4. `index.html` 안의 내용을 모두 지우고 이 폴더의 `index.html`을 통째로 붙여넣습니다.
5. `Ctrl + S`로 저장.

## 3. 설정 바꾸기 (Code.gs 맨 위)
| 항목 | 뜻 |
|---|---|
| `TEACHER_PIN` | **꼭 바꾸세요.** 숫자 6자리 이상 권장. `'0000'` 그대로면 교사 화면이 열리지 않습니다. |
| `APP_TITLE`, `SURVEY_INTRO` | 화면 제목과 안내 문장 |
| `CLASSES` | 반 목록 |
| `MAX_NUMBER` | 번호(선택) 최댓값. 학생이 번호를 적으면 같은 반·번호로 다시 낼 때 덮어씁니다. 번호를 비우면 익명으로 계속 쌓입니다. |
| `QUESTIONS` | **문항 목록.** 여기만 고치면 학생 화면·그래프가 그대로 바뀝니다. |

`QUESTIONS` 고치는 법 (한 줄 = 한 문항):
```js
{ id: 'water', type: 'single', title: '하루에 물을 몇 컵 마시나요?', options: ['1컵 이하', '2~3컵', '4컵 이상'] },
```
- `type`: `'single'` 하나 고르기 / `'multi'` 여러 개(`max: 3`처럼 최대 개수) / `'text'` 글쓰기(`max: 100` 글자 수)
- `id`는 영어로, 문항마다 다르게. 선택지 글자에 쉼표(,)는 넣지 마세요.
- 선택지에 `1/2`, `3-4` 같은 글자는 시트가 날짜로 바꿀 수 있으니 `1~2일`처럼 물결표를 쓰세요.
- **이미 응답을 받은 뒤 문항을 바꾸면** 시트의 `응답` 탭 이름을 `응답(이전)`으로 바꿔 두세요. 새 `응답` 탭이 자동으로 생깁니다(안 바꾸면 화면이 안내 메시지를 띄우고 멈춥니다 — 결과가 엉뚱한 칸에 섞이는 걸 막기 위해서).

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**.
2. **다음 사용자 인증정보로 실행: 나** / **액세스 권한이 있는 사용자: 모든 사용자**.
3. **배포 → 액세스 승인** → 내 계정.
4. "Google에서 확인하지 않은 앱" 경고는 정상 → **고급 → (프로젝트 이름)(으)로 이동 → 허용**.
5. **웹 앱 URL**을 복사해 학생에게(QR 추천).

## 5. 수업에서 쓰기
- 학생: 주소 열기 → 반(번호는 선택) → 문항 답하기 → 제출. 한 기기를 돌려 쓸 땐 "다음 친구가 답하기".
- 교사: **교사 화면** 탭 → PIN →
  - **결과**: 반 칩(전체/1반/…)으로 거르고, 문항별 비율 막대(가장 많은 답은 진하게)
  - **반별 비교**: 문항마다 반별 100% 누적 막대
  - **자동 새로고침(10초)**: 응답이 들어오는 걸 TV로 실시간으로 보여 줄 때
  - **크게 보기**: TV용 큰 글씨. 켜면 **서술 응답 가리기**도 같이 켜집니다(학생 글이 그대로 화면에 뜨지 않게)
  - **CSV 내려받기**: 엑셀에서 열 수 있는 파일(원본은 시트 `응답` 탭에 그대로 있음)

## 6. 코드를 고친 뒤 (같은 주소 유지)
**배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**. 새 배포를 또 만들면 주소가 바뀝니다.

## 막힐 때
| 증상 | 해결 |
|---|---|
| "TEACHER_PIN을 바꾸고…" | `TEACHER_PIN` 바꾸고 저장 → 6번 |
| "문항이 바뀌었어요…" | 시트 `응답` 탭 이름을 `응답(이전)`으로 바꾸기 |
| 학생이 로그인 화면을 봄 | 액세스 권한 **모든 사용자** 확인 / 개인 gmail |
| 고친 문항이 화면에 안 보임 | 저장만 하고 새 버전 배포를 안 함 → 6번 |
| 자동 새로고침이 가끔 멈춤 | 교사 화면 탭을 오래 백그라운드에 두면 브라우저가 늦출 수 있음. 새로고침 버튼 |
