# 실시간 생각 나눔 벽 — 설치 방법 (Firebase 고급)

교사가 질문을 만들면 **4자리 방 코드**가 나오고, 학생은 방 코드 + 모둠/별칭으로 들어와 **쪽지(의견·질문·경험)**를 붙입니다. TV에 띄운 교사 화면에는 쪽지가 **새로고침 없이 바로** 쌓이고, 끌어서 비슷한 쪽지를 묶고, 부적절한 쪽지는 즉시 숨기고, 결과를 CSV/인쇄로 남깁니다.

- 필요한 것: Google 계정(**개인 gmail 권장**), PC 크롬, 이 폴더의 `index.html`, `firestore.rules`
- 걸리는 시간: 20분
- **먼저 구경만 하려면** `index.html`을 더블클릭하세요(**체험 모드**, 이 브라우저에만 저장). 탭을 두 개 열어 한쪽은 **벽(교사) → 체험 교사로 보기 → 방 만들기**, 다른 쪽은 **참여하기**에서 그 코드로 들어가 쪽지를 붙이면 교사 탭에 바로 나타납니다. **샘플 넣기**로 예시 방(쪽지 10장)도 만들 수 있어요.

---

## 0. 꼭 지킬 것 — "새 프로젝트"에만
`firestore.rules`를 붙여넣으면 그 프로젝트의 규칙이 **통째로 바뀝니다.** 이미 다른 사이트·앱이 쓰는 Firebase 프로젝트에 붙이면 그쪽이 조용히 망가집니다. **이 앱만을 위해 새 프로젝트를 만드세요.** (작품 전시회 샘플 fb-gallery와도 **프로젝트를 따로** 만드세요 — 규칙 파일이 서로를 덮어씁니다.)

## 1. 새 Firebase 프로젝트 만들기
https://console.firebase.google.com → **프로젝트 추가** → 이름 예 `idea-wall-2026` → 애널리틱스 꺼도 됨 → 만들기. 요금제는 **Spark(무료)** 그대로.

## 2. 웹 앱 등록 → 설정값 붙여넣기
1. **웹(`</>`) 아이콘** → 닉네임 `wall` → 등록(Hosting 체크 안 함).
2. `firebaseConfig = { ... }`의 **중괄호 안쪽**을 복사해 `index.html` 맨 위 `const FIREBASE_CONFIG = { /* 여기에 붙여넣기 */ };` 중괄호 안에 붙여넣기.
3. `const TEACHER_EMAILS = ['내아이디@gmail.com'];` 에 내 Google 계정.
4. 쪽지 분류 이름을 바꾸고 싶으면 `KINDS`의 `name`·`hint`만 고칩니다(`id`는 규칙과 연결돼 있어 그대로).

> **firebaseConfig는 비밀번호가 아닙니다.** 공식 문서: API 키는 프로젝트를 식별할 뿐이고 데이터는 **보안 규칙**이 지킵니다. → https://firebase.google.com/docs/projects/api-keys

## 3. 로그인 켜기
**Authentication → 시작하기 → Sign-in method** 에서 **익명**(학생), **Google**(교사)을 사용 설정.
공식: https://firebase.google.com/docs/auth/web/anonymous-auth · https://firebase.google.com/docs/auth/web/google-signin

## 4. 데이터베이스 만들기
**Firestore Database → 데이터베이스 만들기** → 위치 **asia-northeast3 (서울)**(나중에 못 바꿈) → 만들기.

## 5. 보안 규칙 붙여넣기
1. Firestore → **규칙** 탭. **새 프로젝트라 기본 내용뿐인지 확인**(다른 내용이 많으면 멈추기).
2. 모두 지우고 `firestore.rules` 붙여넣기 → `isTeacher()`의 `['선생님@gmail.com']`을 2-3과 **똑같이** → **게시**.

> 이 규칙이 서버에서 막는 것: 교사가 아니면 방을 만들거나 쪽지를 숨기/공개/묶지 못함, 학생은 남이 쓴 미공개 쪽지를 읽지 못함, ‘검토 후 공개’ 방에서는 학생 쪽지가 반드시 ‘확인 대기’로 들어감, 닫힌 방에는 못 붙임, 글자 수(쪽지 80자·별칭 12자) 초과 거절.

## 6. GitHub Pages로 배포 (경로 B) + 승인된 도메인
1. 저장소에 `index.html` 올리기 → Pages 주소 예: `https://내아이디.github.io/wall/`
2. **Authentication → 설정 → 승인된 도메인**에 `내아이디.github.io` 추가(안 하면 교사 로그인이 막힘).
3. 내 PC에서 더블클릭(file://)으로 연 상태에선 Google 로그인이 안 됩니다. 실제 모드는 Pages 주소에서.

## 7. 수업에서 쓰기
1. 교사: **벽(교사) → Google로 로그인 → 질문 적기 → 방 만들기**. 처음부터 거르고 싶으면 **검토 후 공개** 체크.
2. TV에 **TV로 보기**(전체 화면, 큰 글씨). 방 코드가 크게 보입니다.
3. 학생: 주소(QR) → 방 코드 + 모둠 이름/별칭(실명 X) → 쪽지 종류 고르기 → 80자 이내 → **벽에 붙이기**. "내 쪽지"에서 상태(벽에 붙음/선생님 확인 중/숨겨짐), "벽 전체"에서 공개된 쪽지 보기.
4. 교사 벽:
   - **분류별**: 의견·질문·경험 3열 / **묶음별**: 묶음 더미 + 아직 안 묶은 쪽지
   - 쪽지를 **끌어 다른 쪽지 위에 놓으면 묶음**(전자칠판 터치도 됨). 묶음 이름은 **이름 바꾸기**. 쪽지를 누르면(또는 Tab → Enter) **크게 보기**에서 묶음 고르기·숨김.
   - **숨김**: 바로 벽과 학생 화면에서 사라짐(아래 "숨긴 쪽지"에서 다시 공개/지우기)
   - **검토 후 공개** 버튼: 켜면 이후 쪽지가 위쪽 노란 칸에 모이고 **공개/숨김**으로 처리
   - **쪽지 받기 멈춤**: 토의를 정리할 때
   - **결과 CSV**(분류·모둠·쪽지·묶음·상태·시각), **인쇄**(쪽지만 깔끔하게)
5. 다음 시간: **지난 질문 열기**에서 다시 열거나, CSV를 받은 뒤 **지우기**.

## 8. 비용 0원 유지
- 쪽지는 글자뿐이라 아주 작습니다(한 장 ≈ 0.5KB). Firestore 무료 한도(하루마다 초기화): **저장 1GiB, 읽기 50,000/일, 쓰기 20,000/일, 삭제 20,000/일**. → https://firebase.google.com/docs/firestore/quotas
- 실시간 화면은 "새로 붙은 쪽지"만 다시 읽습니다. 다만 학생이 **벽 전체**를 켜 두면 쪽지가 붙을 때마다 학생 수만큼 읽기가 생깁니다(30명 × 쪽지 100장 ≈ 3,000회). 여러 반이 하루 종일 써도 보통 한도 안입니다.
- 무료(Spark) 요금제에선 한도를 넘어도 청구되지 않고 그날만 멈춥니다. 사진 저장(Cloud Storage)은 쓰지 않습니다.

## 9. 학교 계정 vs 개인 gmail
- 교사 로그인은 개인 gmail이 무난합니다. 학교 Workspace 계정은 관리자 설정에 따라 막힐 수 있습니다(공식 근거 미확인 경험칙).
- 학생은 계정이 필요 없습니다(익명). 방 코드를 아는 사람은 누구나 쪽지를 붙일 수 있으니, 수업이 끝나면 **쪽지 받기 멈춤**을 누르세요.

## 막힐 때
| 증상 | 해결 |
|---|---|
| "체험 모드"가 계속 보임 | `FIREBASE_CONFIG` 붙여넣기 확인 → 저장 → 새로고침 |
| "권한이 없어요. 보안 규칙…" | 규칙 게시, 규칙의 교사 이메일 = `TEACHER_EMAILS` 인지 |
| 학생이 "번 방이 없어요" | 코드 오타, 또는 교사가 방을 지움 |
| 학생 쪽지가 벽에 안 뜸 | ‘검토 후 공개’가 켜져 있음 → 위쪽 노란 칸에서 공개 |
| 교사 로그인 창이 바로 닫힘 | 팝업 허용, 승인된 도메인(6-2) |

공식 문서: 웹 SDK(이 앱은 `13.2.0` 고정) https://firebase.google.com/support/release-notes/js · 보안 규칙과 로그인 https://firebase.google.com/docs/rules/rules-and-auth
