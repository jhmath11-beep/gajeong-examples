# 실습 재료 신청 & 장보기 목록 — 설치 방법

모둠이 휴대폰으로 실습 메뉴·재료를 신청하면 내 구글 시트에 모이고, 교사 화면에서 **반별 제출 현황 · 장보기 목록(품목별 합계) · 모둠별 신청서 인쇄**를 한 번에 봅니다.

- 필요한 것: 구글 계정(**개인 gmail 권장**), PC 크롬 브라우저, 이 폴더의 `Code.gs`, `index.html`
- 걸리는 시간: 10분 정도
- 먼저 구경만 하려면: `index.html`을 더블클릭하세요. **체험 모드**로 열려서 그 브라우저 안에서만 똑같이 동작합니다(교사 PIN `1234`).

> 학교 Google Workspace 계정은 관리자 설정에 따라 "모든 사용자" 공개가 막혀 있을 수 있습니다(학교마다 다름). 배포 화면에서 "모든 사용자"가 보이지 않으면 개인 gmail로 다시 만드세요.

---

## 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 엽니다.
2. 왼쪽 위 제목을 `실습 재료 신청`처럼 바꿉니다.

## 2. Apps Script 열고 코드 붙여넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다. 새 탭이 열립니다.
2. 왼쪽 파일 목록의 `Code.gs`를 누르고, 안에 있던 내용을 **모두 지운 뒤** 이 폴더의 `Code.gs` 내용을 통째로 붙여넣습니다.
3. 왼쪽 **파일** 옆 **+** 버튼 → **HTML**을 누르고, 이름을 `index` 로 적습니다(`.html`은 자동으로 붙음. 이름이 정확히 `index`여야 합니다).
4. 새로 생긴 `index.html` 안의 내용을 모두 지우고, 이 폴더의 `index.html` 내용을 통째로 붙여넣습니다.
5. 위쪽 **저장(디스크 아이콘)** 또는 `Ctrl + S`.

## 3. 설정 바꾸기 (Code.gs 맨 위)
| 항목 | 뜻 |
|---|---|
| `TEACHER_PIN` | **꼭 바꾸세요.** 교사 화면 비밀번호. 숫자 6자리 이상 권장. `'0000'` 그대로면 교사 화면이 열리지 않습니다. |
| `PRACTICE_TITLE` | 화면 위에 보이는 실습 이름 |
| `CLASSES` | 반 목록 예: `['1반', '2반', '3반']` |
| `GROUPS_PER_CLASS` | 반마다 모둠 수 (미제출 모둠 표시에 씀) |
| `PRACTICE_DATES` | 반별 실습 날짜 `'2026-11-20'` 형식 (모르면 `''`) |
| `MAX_PEOPLE` | 모둠 최대 인원 |

고친 뒤 다시 저장합니다.

**재료 표 고치기:** 처음 한 번 실행되면 시트에 `품목` 탭이 생기고 예시 재료 15개가 들어갑니다. 이후로는 **시트의 `품목` 탭에서 직접** 품목·단위·1인분량·분류를 고치거나 줄을 추가하면 학생 화면에 바로 반영됩니다(1인분량은 예시값이니 메뉴에 맞게 고치세요). 미리 만들어 두려면 Apps Script 위쪽 함수 목록에서 `setup`을 고르고 **▶ 실행**하세요.

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**.
2. **유형 선택(톱니바퀴) → 웹 앱**.
3. 설명: `1차` 아무거나 / **다음 사용자 인증정보로 실행: 나** / **액세스 권한이 있는 사용자: 모든 사용자**
   - "모든 사용자"가 아니면 학생 휴대폰에서 로그인 화면이 뜨거나 열리지 않습니다.
4. **배포** → **액세스 승인** → 내 계정 선택.
5. "Google에서 확인하지 않은 앱" 경고가 나오면 정상입니다(내가 만든 스크립트라서). **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**.
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다. 이게 학생에게 줄 주소입니다.
   - 짧게 만들거나 QR로 띄우면 편합니다.

## 5. 수업에서 쓰기
- 학생(모둠 대표): 주소 열기 → 반·모둠 → 메뉴·인원 → 재료 체크(수량은 1인분량×인원으로 자동, 고칠 수 있음) → 집에서 가져올 재료는 "모둠이 가져옴" → 제출. 다시 내면 덮어씁니다. "우리 모둠이 낸 신청 불러오기"로 고쳐서 다시 낼 수 있습니다.
- 교사: 같은 주소 → **교사 화면** 탭 → PIN → 반 고르기(여러 반 함께 가능) → 제출 현황(빨간 칸=미제출) / 장보기 목록 / 장보기표 인쇄 / 모둠별 신청서 인쇄.
- 모든 원본은 시트 `신청` 탭에 품목 1개 = 1줄로 남습니다.

## 6. 코드를 고친 뒤 (같은 주소 유지)
**새 배포를 또 만들면 주소가 바뀝니다.** 같은 주소를 쓰려면:
**배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**.
(저장만 하고 이 과정을 안 하면 학생 화면에는 예전 코드가 계속 보입니다.)

## 막힐 때
| 증상 | 해결 |
|---|---|
| 교사 화면에서 "TEACHER_PIN을 바꾸고…" | Code.gs의 `TEACHER_PIN`을 바꾸고 저장 → 6번(새 버전 배포) |
| 학생 휴대폰에서 로그인하라고 나옴 | 배포 관리에서 액세스 권한이 **모든 사용자**인지 확인. 학교 계정이면 개인 gmail로 |
| "Script function not found: doGet" | Code.gs를 붙여넣고 저장했는지, 함수 이름을 바꾸지 않았는지 확인 |
| 화면이 하얗게 나옴 / `index` 오류 | HTML 파일 이름이 정확히 `index`인지 확인 |
| 품목 표에 없는 재료라고 나옴 | 학생이 화면을 연 뒤 교사가 `품목` 탭을 고친 경우. 학생 화면 새로고침 |
| PIN을 너무 많이 틀렸다고 나옴 | 10분 뒤 다시. (여러 번 틀리면 잠깐 잠기는 보호 기능) |
