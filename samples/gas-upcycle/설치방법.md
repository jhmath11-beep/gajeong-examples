# 업사이클링 모둠 프로젝트 진행 보드 — 설치 방법

모둠이 휴대폰으로 **작업표**를 열어 단계(조사 → 디자인 구상 → 재료 준비 → 제작 → 발표)별 체크, **진행 메모·다음 할 일·막힌 점**을 저장하면 내 구글 시트에 모이고, 교사 화면에서 **반 전체 진행 현황판(단계별 열), 막힌 점 모아보기, 모둠별 선생님 메모 한 줄(학생 화면에 보임), 오래 멈춘 모둠 표시, CSV**를 봅니다. TV에는 **크게 보기**(메모 자동 가림)로 띄웁니다.

- 필요한 것: 구글 계정(**개인 gmail 권장**), PC 크롬 브라우저, 이 폴더의 `Code.gs`, `index.html`
- 걸리는 시간: 10분 정도
- 먼저 구경만 하려면: `index.html`을 더블클릭하세요. **체험 모드**로 열려서 그 브라우저 안에서만 똑같이 동작합니다. **샘플 넣기**를 누르면 1반·2반 모둠 11개가 들어가고, 샘플 모둠 비밀번호는 모두 `1111`, 교사 PIN은 `1234`입니다.

> 학교 Google Workspace 계정은 관리자 설정 때문에 "모든 사용자" 공개가 막히는 경우가 있습니다(공식 문서 근거는 확인하지 못한 경험칙). 막히면 개인 gmail로 다시 만드세요.
>
> 개인정보: 이름은 받지 않습니다(반·모둠만). 모둠 비밀번호는 시트에 그대로 저장되지 않고 **해시(알아볼 수 없게 바꾼 값)**만 저장됩니다. 막힌 점·메모에는 모둠 사정이 적힐 수 있으니 TV에는 **크게 보기**(메모 가림)로만 띄우세요.

---

## 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 엽니다.
2. 제목을 `업사이클링 진행 보드`처럼 바꿉니다.

## 2. Apps Script 열고 코드 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**.
2. 왼쪽 `Code.gs` 내용을 **모두 지우고** 이 폴더의 `Code.gs`를 통째로 붙여넣기.
3. **파일** 옆 **+** → **HTML** → 이름 `index` (정확히 `index`).
4. `index.html` 내용을 모두 지우고 이 폴더의 `index.html`을 통째로 붙여넣기.
5. `Ctrl + S`로 저장.

## 3. 설정 바꾸기 (Code.gs 맨 위)
| 항목 | 뜻 |
|---|---|
| `TEACHER_PIN` | **꼭 바꾸세요.** 숫자 6자리 이상 권장. `'0000'` 그대로면 교사 화면이 열리지 않습니다. |
| `PROJECT_NAME` | 프로젝트 이름. **새 프로젝트를 할 때 이 이름만 바꾸면** 따로 모입니다(이전 기록은 시트에 남음). |
| `CLASSES`, `GROUPS_PER_CLASS` | 반 목록, 반마다 모둠 수('시작 전' 모둠 확인에 씀) |
| `STALE_DAYS` | 이 날수 넘게 저장이 없으면 현황판에 **n일째 멈춤** 표시(기본 3일) |
| `STAGES` | **단계와 단계별 체크 항목.** `name`과 `checks`를 수업에 맞게 고치세요. `id`는 영어로 서로 다르게, 한번 정하면 그대로. |

- 진행 중에 단계 수·이름을 바꾸면 시트 `모둠` 탭 이름을 `모둠(이전)`으로 바꿔 두세요. 새 탭이 자동으로 생깁니다.

## 4. 웹 앱으로 배포
1. **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**.
2. **다음 사용자 인증정보로 실행: 나** / **액세스 권한이 있는 사용자: 모든 사용자**.
3. **배포 → 액세스 승인** → 내 계정.
4. "Google에서 확인하지 않은 앱" 경고는 정상 → **고급 → (프로젝트 이름)(으)로 이동 → 허용**.
5. **웹 앱 URL**을 복사해 학생에게(QR 추천).

## 5. 수업에서 쓰기
- 첫 시간: 모둠마다 **모둠 비밀번호 4자리**를 정하게 하세요. 처음 저장할 때 쓴 번호가 모둠 비밀번호가 됩니다.
- 모둠: **우리 모둠** 탭 → 반·모둠·비밀번호 → **작업표 열기** → 지금 단계 체크 → 진행 메모·다음 할 일·막힌 점 → **작업표 저장**. 한 단계를 다 채우면 다음 단계가 펼쳐집니다. 모둠원 누구나 고칠 수 있고, 같은 모둠은 한 줄을 덮어씁니다.
  - 두 모둠원이 동시에 고치면 나중에 저장한 쪽에 "다른 모둠원이 방금 저장했어요"가 뜹니다 → **다시 불러오기** 후 고쳐서 저장(서로 지우는 사고 방지).
  - 선생님이 남긴 메모는 작업표 위에 손글씨로 보입니다.
- 교사: **현황판 (교사)** 탭 → PIN →
  - **현황판**: 시작 전 | 조사 | 디자인 구상 | 재료 준비 | 제작 | 발표 | 완료 열에 모둠 작업표가 놓입니다. 칸 5개는 단계 진행, 점선 테두리는 오래 멈춘 모둠. 카드의 **메모 남기기** → 한 줄 피드백(학생 화면에 보임, 빈칸 저장 = 지우기)
  - **막힌 점**: 막힌 점을 적은 모둠만 모아, 그 자리에서 바로 메모 남기기
  - **모둠 표**: 단계별 체크 수·마지막 저장·메모 전체, 모둠 **비밀번호 초기화**
  - **크게 보기**: TV용. 메모는 자동으로 가려지고(선생님 메모는 보임), 오른쪽 위 버튼으로 가림을 켜고 끕니다
  - **CSV**: 모둠별 요약(단계별 체크, 멈춘 날수, 메모)

## 6. 코드를 고친 뒤 (같은 주소 유지)
**배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**. 새 배포를 또 만들면 주소가 바뀝니다.

## 막힐 때
| 증상 | 해결 |
|---|---|
| "TEACHER_PIN을 바꾸고…" | `TEACHER_PIN` 바꾸고 저장 → 6번 |
| 모둠이 비밀번호를 잊음 | 교사 화면 **모둠 표 → 초기화** → 그 모둠이 다음에 저장할 때 쓴 번호가 새 비밀번호 |
| "비밀번호를 너무 많이 틀렸어요" | 10번 틀리면 그 모둠은 10분 잠깁니다. 초기화하면 바로 풀려요 |
| "단계 설정이 바뀌었어요…" | 시트 `모둠` 탭 이름을 `모둠(이전)`으로 |
| 학생이 로그인 화면을 봄 | 액세스 권한 **모든 사용자** 확인 / 개인 gmail |
| 고친 단계가 안 보임 | 새 버전 배포 안 함 → 6번 |
