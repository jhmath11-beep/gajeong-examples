# 학급 나눔 장터 (물물교환 게시판) — 설치 방법

학생이 휴대폰으로 **안 쓰는 물건을 게시판에 붙이고, 다른 친구 물건에 교환 신청**을 합니다. 물건 주인이 신청을 수락하면 두 물건 모두 **교환 완료 도장**이 찍히고, 교사 화면에서 **부적절한 글 숨김·삭제, 분류별 등록·완료 수, '버려질 뻔한 물건 n개 재사용', CSV**를 봅니다.

- 필요한 것: 구글 계정(**개인 gmail 권장**), PC 크롬 브라우저, 이 폴더의 `Code.gs`, `index.html`
- 걸리는 시간: 10분 정도
- 먼저 구경만 하려면: `index.html`을 더블클릭하세요. **체험 모드**로 열려서 그 브라우저 안에서만 똑같이 동작합니다. **샘플 넣기**를 누르면 물건 20개가 붙고, 샘플 별칭 비밀번호는 모두 `1111`(예: 2반 초록고래), 교사 PIN은 `1234`입니다.

> 학교 Google Workspace 계정은 관리자 설정 때문에 "모든 사용자" 공개가 막히는 경우가 있습니다(공식 문서 근거는 확인하지 못한 경험칙). 막히면 개인 gmail로 다시 만드세요.
>
> 개인정보: 이름·전화번호는 받지 않습니다. 학생은 **반 + 별칭 + 숫자 4자리 비밀번호**만 씁니다. 비밀번호는 시트에 그대로 저장되지 않고 **해시(알아볼 수 없게 바꾼 값)**만 저장됩니다. 글에 전화번호처럼 보이는 숫자를 쓰면 서버가 거절합니다. 실제 물건 교환은 **선생님이 정한 장소·시간**(예: 점심시간 가사실 앞)에서 하도록 안내하세요.

---

## 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 엽니다.
2. 제목을 `나눔 장터`처럼 바꿉니다.

## 2. Apps Script 열고 코드 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**.
2. 왼쪽 `Code.gs` 내용을 **모두 지우고** 이 폴더의 `Code.gs`를 통째로 붙여넣기.
3. **파일** 옆 **+** → **HTML** → 이름 `index` (정확히 `index`).
4. `index.html` 내용을 모두 지우고 이 폴더의 `index.html`을 통째로 붙여넣기.
5. `Ctrl + S`로 저장.

## 3. 설정 바꾸기 (Code.gs 맨 위)
| 항목 | 뜻 |
|---|---|
| `TEACHER_PIN` | **꼭 바꾸세요.** 숫자 6자리 이상 권장. `'0000'` 그대로면 교사 화면이 열리지 않습니다. |
| `CLASSES` | 반 목록 |
| `CATEGORIES` | 물건 분류(학용품·책·옷·잡화…). 수업에 맞게 고치세요. |
| `CONDITIONS` | 상태 3단계의 설명. `name`(상·중·하)은 그대로 두고 `desc`만 고치세요. |
| `MAX_ITEMS_PER_PERSON` | 한 사람이 동시에 올려 둘 수 있는 물건 수(교환 끝난 물건은 빼고 셈) |

## 4. 웹 앱으로 배포
1. **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**.
2. **다음 사용자 인증정보로 실행: 나** / **액세스 권한이 있는 사용자: 모든 사용자**.
3. **배포 → 액세스 승인** → 내 계정.
4. "Google에서 확인하지 않은 앱" 경고는 정상 → **고급 → (프로젝트 이름)(으)로 이동 → 허용**.
5. **웹 앱 URL**을 복사해 학생에게(QR 추천).

시트에는 탭 3개가 자동으로 생깁니다: `물건`(게시물), `신청`(교환 신청), `사람`(반·별칭·비밀번호 해시).

## 5. 수업에서 쓰기
- 시작 전: "실명 말고 **별칭**, 비밀번호는 **숫자 4자리**, 잊으면 그 별칭은 못 씀(새 별칭으로)"을 꼭 말해 주세요.
- 학생
  - **올리기**: 이름표(반·별칭·비밀번호) → 물건 이름·분류·상태(상·중·하)·원하는 교환·한 줄 이야기 → **게시판에 붙이기**. 오른쪽(휴대폰은 아래)에 게시판에 붙을 모습이 미리 보입니다. **원하는 교환을 비우면 '그냥 나눔'**이 되어, 받는 친구는 내 물건 없이도 신청할 수 있어요.
  - **게시판**: 분류 버튼·찾기·'끝난 거래도 보기'로 살펴보고 전단지 아래 **교환 신청** → 내놓을 내 물건 고르기 + 한 줄 메시지.
  - **내 장터**: 내 물건에 온 신청을 **수락/거절**. 수락하면 두 물건 모두 '교환 완료', 같은 물건에 걸린 다른 신청은 자동으로 '다른 교환으로 끝남'. 내가 보낸 신청의 결과도 여기서 봅니다.
- 교사: **교사** 탭 → PIN →
  - 손글씨 줄: **버려질 뻔한 물건 n개 재사용** (교환 완료된 물건 수)
  - **분류별 거래**: 분류마다 올린 수·교환 완료 수·완료 비율
  - **게시물 관리**: 부적절한 글은 **숨김**(게시판에서 사라지고 신청도 막힘, 다시 **보이기** 가능). 정말 지워야 하면 **삭제**(되돌릴 수 없음)
  - **CSV**: 게시물 전체(숨김 포함)

## 6. 코드를 고친 뒤 (같은 주소 유지)
**배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**. 새 배포를 또 만들면 주소가 바뀝니다.

## 막힐 때
| 증상 | 해결 |
|---|---|
| "TEACHER_PIN을 바꾸고…" | `TEACHER_PIN` 바꾸고 저장 → 6번 |
| 학생이 비밀번호를 잊음 | 시트 `사람` 탭에서 그 반·별칭 줄을 지우면, 다음에 쓰는 번호가 새 비밀번호가 됩니다(그 별칭의 물건·신청은 그대로) |
| "비밀번호를 너무 많이 틀렸어요" | 10번 틀리면 그 별칭은 10분 잠깁니다. 기다리면 풀려요 |
| "한 사람이 동시에 올릴 수 있는 물건은…" | `MAX_ITEMS_PER_PERSON`을 늘리거나, 교환이 끝나길 기다리기 |
| 학생이 로그인 화면을 봄 | 액세스 권한 **모든 사용자** 확인 / 개인 gmail |
| 고친 설정이 안 보임 | 새 버전 배포 안 함 → 6번 |
