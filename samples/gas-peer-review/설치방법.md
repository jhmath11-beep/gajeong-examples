# 모둠 활동 자기·동료평가 수합 — 설치 방법

학생이 휴대폰으로 **자기평가 + 같은 모둠원 각자 평가 + 한 줄 칭찬/조언**을 내면 내 구글 시트에 모이고, 교사 화면에서 **자기 점수 vs 동료 평균, 항목별 평균, 차이 큰 학생, 미제출자, 피드백 모아보기, CSV**를 봅니다.

- 필요한 것: 구글 계정(**개인 gmail 권장**), PC 크롬 브라우저, 이 폴더의 `Code.gs`, `index.html`
- 걸리는 시간: 10분 정도
- 먼저 구경만 하려면: `index.html`을 더블클릭하세요. **체험 모드**로 열려서 그 브라우저 안에서만 똑같이 동작합니다(교사 PIN `1234`).

> 학교 Google Workspace 계정은 관리자 설정 때문에 "모든 사용자" 공개가 막히는 경우가 있습니다(공식 문서 근거는 확인하지 못한 경험칙). 막히면 개인 gmail로 다시 만드세요.
>
> 동료평가 결과는 학생에게 민감할 수 있습니다. 교사 화면 주소와 PIN을 학생에게 보여 주지 말고, 수업 중 TV에는 **크게 보기**(한마디 자동 가림)로만 띄우세요. 점수는 성적 산출의 참고 자료로만 쓰기를 권합니다.

---

## 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 엽니다.
2. 제목을 `모둠 동료평가`처럼 바꿉니다.

## 2. Apps Script 열고 코드 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**.
2. 왼쪽 `Code.gs` 내용을 **모두 지우고** 이 폴더의 `Code.gs`를 통째로 붙여넣기.
3. **파일** 옆 **+** → **HTML** → 이름 `index` (정확히 `index`).
4. `index.html` 내용을 모두 지우고 이 폴더의 `index.html`을 통째로 붙여넣기.
5. `Ctrl + S`로 저장.

## 3. 설정 바꾸기 (Code.gs 맨 위)
| 항목 | 뜻 |
|---|---|
| `TEACHER_PIN` | **꼭 바꾸세요.** 숫자 6자리 이상 권장. `'0000'` 그대로면 교사 화면이 열리지 않습니다. |
| `EVAL_NAME` | 평가 이름 예: `'조리실습 3차'`. **새 평가를 할 때 이 이름만 바꾸면** 따로 모입니다(이전 기록은 시트에 남고 화면에는 지금 평가만 보임). |
| `CLASSES`, `GROUPS_PER_CLASS` | 반 목록, 반마다 모둠 수(미제출 확인에 씀) |
| `MAX_GROUP_SIZE` | 모둠 최대 인원 |
| `DIFF_ALERT` | 자기 평균 − 동료 평균 차이가 이 값 이상이면 표에 색으로 표시(기본 1.0점) |
| `SCORE_LABELS` | 1~5점의 뜻 |
| `CRITERIA` | **루브릭 항목(4~5개 권장).** `name`(짧은 이름)과 `desc`(설명)를 수업에 맞게 고치세요. `id`는 영어로 서로 다르게. |

- 평가를 받기 시작한 뒤 `CRITERIA`를 바꾸면 시트 `평가` 탭 이름을 `평가(이전)`으로 바꿔 두세요. 새 탭이 자동으로 생깁니다.

## 4. 웹 앱으로 배포
1. **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**.
2. **다음 사용자 인증정보로 실행: 나** / **액세스 권한이 있는 사용자: 모든 사용자**.
3. **배포 → 액세스 승인** → 내 계정.
4. "Google에서 확인하지 않은 앱" 경고는 정상 → **고급 → (프로젝트 이름)(으)로 이동 → 허용**.
5. **웹 앱 URL**을 복사해 학생에게(QR 추천).

## 5. 수업에서 쓰기
- 시작 전: 모둠마다 **모둠 안 번호(1, 2, 3…)**를 정하게 하세요. 이름은 받지 않습니다.
- 학생: 반·모둠·모둠 인원·내 번호 → **평가 시작하기** → "나(자기평가)" 카드부터 모둠원 카드마다 항목별 1~5점 → 모둠원에게 칭찬/조언 한 줄(필수) → 제출. 다시 내면 덮어씁니다.
- 교사: **교사 화면** 탭 → PIN →
  - 숫자 카드: 제출 학생 / 미제출 / 차이 큰 학생 수 / 동료평가 전체 평균
  - **항목별 평균**: 자기(청록) vs 동료(분홍)
  - **미제출**: 모둠원이 적은 "모둠 인원" 기준으로 안 낸 번호, 아무도 안 낸 모둠
  - **학생별 표**: 자기 / 동료 평균 / 차이 / 항목별 동료 평균. **차이 큰 순** 정렬로 상담할 학생 찾기
  - **받은 칭찬·조언**: 학생별로 모아보기(TV에선 가림)
  - **CSV 내려받기**: 학생별 요약. 원본(누가 누구를 몇 점)은 시트 `평가` 탭

## 6. 코드를 고친 뒤 (같은 주소 유지)
**배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포**. 새 배포를 또 만들면 주소가 바뀝니다.

## 막힐 때
| 증상 | 해결 |
|---|---|
| "TEACHER_PIN을 바꾸고…" | `TEACHER_PIN` 바꾸고 저장 → 6번 |
| "평가 항목이 바뀌었어요…" | 시트 `평가` 탭 이름을 `평가(이전)`으로 |
| 미제출 인원이 이상함 | 모둠원끼리 "모둠 인원"을 다르게 적은 경우 → 가장 큰 값 기준으로 계산됨 |
| 학생이 로그인 화면을 봄 | 액세스 권한 **모든 사용자** 확인 / 개인 gmail |
| 고친 항목이 안 보임 | 새 버전 배포 안 함 → 6번 |
